About

Export titlova za CapCut (Serbian Transcriber) turns Serbian speech from MP4 and MOV videos into downloadable SRT subtitles you can import straight into CapCut, plus clean plain text — built for TikTok, YouTube Shorts, Instagram Reels, interviews and podcasts.

Workflow: video → titlove → CapCut

  1. Upload the video here.
  2. Click Download SRT — you get a file named like video.sr.srt.
  3. In CapCut: Text → Import subtitles → Import file and pick the .srt.
  4. CapCut splits the timeline for you; then style, animate and export.

Timestamps come straight from the model, so the timing matches the audio. Edits you make here before download are reflected in the file CapCut imports.

How it works

  1. You drop in a video (MP4 or MOV).
  2. Your browser uploads it over HTTPS to our API server.
  3. The server sends the audio to Groq's Whisper speech-to-text model.
  4. You get segment- and word-level timestamps, rendered as editable lines.
  5. Download a valid SRT, a clean TXT, or copy any line.

Technology

  • Frontend: plain HTML5 + CSS3 + vanilla JavaScript (GitHub Pages friendly).
  • Backend: Node.js + Express, with the API key kept strictly server-side.
  • Speech recognition: Groq Speech-to-Text (Whisper large-v3 / large-v3-turbo).

Serbian first

Serbian Latin and Cyrillic, diacritics (č ć š ž đ), natural punctuation — the output preserves whatever script the model recognizes. You can also hint the language: Serbian, English, Croatian, Bosnian or Montenegrin.

Editing

Every line can be edited before download. Timestamps stay untouched unless you explicitly change them. "Regenerate SRT" and "Regenerate TXT" rebuild files from the current on-screen content.
