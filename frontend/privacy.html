Privacy

Last updated: October 2026

What we receive

  • The video file you upload (MP4 or MOV).
  • The language hint you pick in the selector.

What we do with it

  • Your video is streamed to a temporary file on the server and deleted immediately after transcription.
  • We do not store, copy, share or analyze your videos.
  • Only the audio track is sent to Groq's speech-to-text API — for larger videos or MOV files, the audio is extracted (mono 16 kHz) before the call.
  • We never sell data. There are no ads and no third-party trackers.

API key safety

The Groq API key lives only on the backend as an environment variable. It is never included in the frontend JavaScript served by GitHub Pages, so it cannot be extracted from your browser.

Logs

The server logs technical metadata (file size, duration, error codes) for debugging. Logs never contain video content, transcription text, or secrets.

Your control

Nothing persists: once the response is sent and the temp file is deleted, no copy of your video or transcript remains on the server. You can also clear the page at any time — everything lives in your browser tab until you close it.
